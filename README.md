# Green Hell Admin Hub Mockup

Interactive design preview: https://phonra1620.github.io/jobza_gh_mod/

Open the link and try Solo / Host / Client menus, the game reference lists,
EN/TH, and simulated mod controls. This website does not connect to or control
Green Hell. Inventory and test results are published snapshots, not live scans.
New features marked pending have not been validated in every game mode.

GitHub Pages publishes the `docs/` folder from `main`. All paths are relative
to support project-site hosting. No server, Node installation, or build is
needed by visitors. Private chat history, internal roadmap documents, local
machine paths, mod binaries, and credentials are excluded from this repository.

Run `node checks/check-public.mjs` to check static assets and public routes.
